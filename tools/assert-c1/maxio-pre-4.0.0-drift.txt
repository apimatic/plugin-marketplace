# Known failures for the PRE-4.0.0 core surface (maxio-sdk's SDK).
#
# assert-c1's 328 general assertions describe generator 4.0.0. Run against a pre-4.0.0
# fixture, 100 of them fail BY CONSTRUCTION — the surface really is different, and maxio's
# own dotnet-* skills already say so in their provenance stamps. Baselining them here means
# the job goes red when this delta CHANGES rather than sitting red forever, which is the only
# way a known-failing check stays worth reading.
#
# Two things this catches that a plain 'skip maxio' would not:
#   - a 4.0.0 behaviour APPEARING here (the SDK was regenerated) shows up as a resolved entry;
#   - a baselined failure going UNSETTLEABLE shows up separately, because 'the fixture can no
#     longer answer this' is not the same as 'this was fixed'.
#
# The positive claims for this surface live in assertions/15-pre-4.0.0.json and are expected
# to PASS. This file is only the 4.0.0-shaped half that cannot hold here.
#
# Regenerate with:  python tools/assert-c1/assert_c1.py <maxio-sdk> --surface pre-4.0.0
